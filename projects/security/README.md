# Resumen de incidente de seguridad

Ejercicio reconstruido con ayuda de IA después de completar el plan de formación. Los datos son ficticios.

- `input.*`: entrada de prueba.
- `prompt.txt`: instrucciones con contexto, restricciones y formato.
- `reference.json`: resultado de referencia redactado con ayuda de IA; no es una salida de IBM Granite.

## Evaluación

Comprobar que no se inventan accesos, exfiltración o acciones realizadas. Las recomendaciones deben distinguirse de los hechos.

El validador comprueba estructura y consistencia básica, no la verdad ni la calidad semántica. La revisión del contenido debe hacerse por separado.

## Iteración propuesta

Comparar un prompt general con el prompt estructurado, usando la misma entrada y el mismo modelo. Registrar errores, ajustar el prompt y repetir. Este repositorio no afirma que ese experimento se haya ejecutado.
